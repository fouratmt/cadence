# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS and JavaScript with browser-native APIs. The implementation uses a build-free layout for GitHub Pages and avoids runtime dependencies.

## Users

People timing workouts on a phone, with the same tools available on a desktop. During an interval, the active phase and remaining time should be readable at a glance.

## Capabilities and Constraints

Rounds, Tabata, stopwatch laps, and named interval presets. Presets and preferences live on the device. The app can be installed and used offline after the first successful load. Workout cues include beeps, optional spoken cues, and optional screen flashes. Screen Wake Lock is used when the browser grants it during a running timer. The supplied screenshots establish the visual direction for the phase colors, large time display, interval editor, and settings.
